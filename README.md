- `resume.html` — short application-ready resume
- `contact.html` — contact page with Asha's email
- `style.css` — complete responsive design

## Publish it
1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload ALL files from this ZIP to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch** → `main` → `/ (root)` → Save.
5. Your public application link will be:
   `https://YOURUSERNAME.github.io/`
